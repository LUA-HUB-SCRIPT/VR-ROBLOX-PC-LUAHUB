VIRTUAL VR
FOR ROBLOX

Ubah smartphone menjadi controller untuk Roblox PC. Gunakan kamera HP untuk mencoba head tracking dan hand tracking, serta kontrol permainan melalui koneksi lokal.

FEATURES

📷

Camera Tracking

Gunakan kamera HP untuk mendeteksi landmark wajah dan tangan.

🎮

Virtual Controller

Kontrol WASD, Jump, Sprint, Crouch, dan Interact dari layar HP.

🔗

PC Connection

Hubungkan HP ke PC melalui USB atau jaringan Wi-Fi lokal.

HOW IT WORKS

01

Install PC App

Jalankan aplikasi LUAHUB Virtual VR di Windows.

02

Connect Phone

Sambungkan HP menggunakan USB atau Wi-Fi.

03

Start Controlling

Buka Control, aktifkan kamera, dan gunakan controller.

INSTALLATION GUIDE

1. Download versi Windows dari GitHub Releases.
2. Ekstrak file jika dikemas dalam ZIP.

4. Hubungkan HP menggunakan USB atau Wi-Fi.
5. Buka halaman Control.

IMPORTANT NOTICE

LUAHUB Virtual VR adalah controller eksperimental. Sistem ini bukan headset VR native, tidak menyediakan tampilan stereoskopik, dan belum menggunakan OpenXR. Head tracking saat ini mengirim data koordinat ke server, bukan menggerakkan kamera Roblox secara otomatis.
